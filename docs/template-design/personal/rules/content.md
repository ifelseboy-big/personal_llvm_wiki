# 内容包语义

`content-pack.json` 是分类、类型、字段、关系、生命周期检索语义、模板和 Workflow 路由的唯一机器权威来源。本文件不重复其中的值域。

Agent 必须：

1. 先读取当前策略，确认 name、version 与实例一致。
2. 独立选择 category（领域）和 type（结构），不得把领域当结构或反向推断。
3. 读取所选 type 的 template 与字段声明；按模板的适用条件、边界、来源和验证小节生成自包含草稿。
4. 保留已有未知用户属性；不补旧版本字段，不猜测缺失值。
5. 根据 lifecycle 声明处理默认召回、争议、有效期和复核日期，不在说明文档维护第二份状态枚举。

配置类内容禁止写入密码、Token、私钥、cookie、恢复码或可直接使用的凭据。只记录非敏感配置知识、影响、验证方式和秘密管理系统中的安全引用位置。
