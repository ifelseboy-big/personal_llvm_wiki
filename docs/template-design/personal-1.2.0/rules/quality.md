# 质量检查

发布前逐项确认。

## 事实与范围

- 核心结论可从正文引用回到真实 raw 资料。
- 观察、原话、推断和建议没有混写成同一层事实。
- 标题准确表达内容，不使用“杂记”“其他”等弱标题。
- 一篇文档只有一个主要用途；混合用途已拆分并建立关系。
- 适用条件、版本、时间范围和例外已写清楚。

## 生命周期与关系

- `lifecycle` 与当前证据一致。
- 到期或待复核知识没有被无警告地当作当前事实。
- `related` 指向实际文件，`supersedes` 与 `superseded_by` 成对一致。
- 冲突来源均被保留；未解决冲突使用 `disputed`。

## 可执行性与可检索性

- `guide` 有结果验证和失败/回滚说明。
- `tutorial` 有明确学习成果和阶段检查点。
- `reference` 的字段、单位、默认值和兼容范围明确。
- `decision` 记录备选项、驱动因素、后果和重新评估条件。
- `project` 标明 `as_of`，不把动态任务列表伪装成事实快照。
- `description` 能在搜索结果中独立说明文档价值。

## 模板卫生

- 没有 `{{title}}`、`{{date}}`、`{{time}}` 或其他未解析变量。
- 没有 `%% llm-wiki:prompt ... %%` 注释。
- 一级标题与 `title` 一致。
- 空的可选属性已省略，列表和日期类型正确。
- 不包含重复知识、敏感信息或无授权的受限内容。
